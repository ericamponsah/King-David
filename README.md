# King David — A Cinematic Animation

An HD cinematic web animation telling the epic, God-breathed story of **King David** — shepherd boy, giant-slayer, hunted fugitive, and ultimately the crowned King of Israel.

## Story Arc

| # | Scene | Key Scripture |
|---|-------|---------------|
| 1 | Prologue — The Fields of Bethlehem | Psalm 91:1 |
| 2 | Life in the Wilderness | Psalm 91:3 |
| 3 | The Lion & The Bear | Psalm 91:13 |
| 4 | Cold Nights, Hunger & Thirst | Psalm 91:5–6 |
| 5 | Prophet Samuel Visits Jesse | 1 Samuel 16 |
| 6 | Jesse Forgets David | 1 Samuel 16:11 |
| 7 | David Anointed | 1 Samuel 16:13 |
| 8 | Goliath's Challenge | 1 Samuel 17:10 |
| 9 | David vs Goliath | 1 Samuel 17:45–47 |
| 10 | King Saul Hunts David | Psalm 91:7 |
| 11 | Ascending the Golden Throne | 2 Samuel 5:3 |
| 12 | Psalm 23 — The Shepherd King | Psalm 23 (full) |
| 13 | Epilogue | Psalm 91 (full) |

## Voice-Over

The entire animation is underscored by the full text of **Psalm 91**, displayed as a continuous narration strip that scrolls alongside each scene.

## How to Run

Open `index.html` in any modern browser — no build step required.

```bash
# Serve locally (optional)
npx serve .
# or
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080`.

## Technology

- Pure HTML5 / CSS3 / Vanilla JavaScript
- CSS keyframe animations for cinematic transitions
- Canvas-based starfield and particle effects
- No external dependencies
